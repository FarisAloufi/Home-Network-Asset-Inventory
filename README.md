# Home Network Asset Inventory

## 📌 Project Overview
This project involved building an asset inventory for a home network used to run a small business, identifying which devices connect to the network, their key characteristics, and how sensitive each one is. The goal was to practice a fundamental first step in any security framework: knowing what assets exist before you can protect them.

## 🎯 Objectives
- Identify devices connected to a home/business network.
- Document each device's network access pattern, owner, and location.
- Assess how each device could impact confidentiality, integrity, or availability if compromised.
- Classify each asset using a standard sensitivity scale.

## 🛠️ Skills & Concepts Demonstrated
- Asset identification and inventory management
- Data classification (Confidential / Restricted / Internal-only / Public)
- Risk-based thinking: confidentiality, integrity, and availability (CIA triad)
- Documentation of security-relevant device characteristics
